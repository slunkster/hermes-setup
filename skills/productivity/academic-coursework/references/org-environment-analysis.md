# Organisation external environment analysis (organisation theory courses)

Course readings seen: A. Rosenberg (2011) handout summarising Hatch (2006)
"Organization and Environment"; H. Roots (2013) *Loenguid
organisatsiooniteooriast* (3. tr), Sisekaitseakadeemia, ch. 3 "Organisatsioon
ettearvamatus keskkonnas" pp. 49-57.

## Concepts to use (with citation anchors)
- Hatch (modernist): environment outside org boundary gives inputs, absorbs
  outputs, constrains; org is dependent + uncertain. Steps: define org →
  identify links (stakeholder model) → analyse general-environment trends →
  assess impact → reflect on own biases.
- Hatch general environment sectors: social, cultural, legal, political,
  economic, technological, physical. Network: suppliers, customers,
  competitors, partners, unions, interest groups, regulators.
- Symbolic-interpretive: environment is socially constructed via managers'
  interpretation (good for "we see competitors as partners").
- Postmodern: blurred org boundaries; Freeman — orgs that listen to all
  stakeholders outperform those ignoring some; CSR/sustainability.
- Roots: internal vs external; external = macro (indirect: economic,
  political, legal, sociocultural, technological trends, EU) and micro
  (direct: suppliers, consumers, competitors, partners, regulators).
- Roots: complexity (number + diversity of critical factors) × variability
  (pace of change) → uncertainty (figs 7-9: info overload / info hunger).
  Turbulent environment: novelty, speed, pressure, loss of control; prepare
  for worst, save resources. Meristö (1991, Roots 2013 kaudu): future can't
  be predicted but can be influenced; ask what is possible / probable /
  necessary. Strategic thinking over strategic planning.

## Applying to a grant/municipality-funded NGO (e.g. a youth hub)
- Treat funders (municipality, EU/regional projects) as the critical
  "suppliers" and also de-facto regulators; resource dependence on few
  sources is the core risk.
- Political sector usually dominant (council/coalition change can cut
  funding); economic sector = project-based, time-limited money.
- Physical/social: sparse settlement and youth out-migration → outreach
  programmes as the org's response.
- Discussion: rate uncertainty via complexity × variability, then show
  existing actions (extra projects, own income, partnerships) as responses.
