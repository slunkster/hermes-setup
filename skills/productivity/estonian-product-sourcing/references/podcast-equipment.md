# Podcast equipment sourcing

## Build complete alternatives

1. Establish the simultaneous local participant count and use it as the minimum number of microphone preamps, not merely advertised total inputs. For an unspecified ordinary group podcast, compare dynamic XLR microphones first; close placement is practical in untreated rooms, but no mic eliminates room echo.
2. Compare a standalone recorder path with a computer/interface path. State explicitly whether an existing computer is required. Do not treat four independent USB microphones as a simple equivalent of a four-preamp interface; aggregation and clock/driver handling add complexity.
3. Build each basket with one mic, XLR cable, usable stand and monitoring headset per participant. Check whether mic packs already include these before adding duplicates. Include a compatible memory card for standalone recording and a power supply/cable or explicitly assumed existing power source.
4. Check headphone output count. If the interface lacks enough outputs, include an appropriate headphone distribution amplifier and its input cable. Verify connector sizes and any adapters.
5. Confirm that all microphones can record simultaneously to separate tracks through the intended workflow. USB channel count and memory-card recording capability are separate specifications; four XLR sockets do not prove four isolated channels over USB.
6. Present two or three meaningfully different baskets, complete totals, the computer requirement, one practical drawback and a recommendation. Distinguish checked product prices from accessory/delivery allowances. Confirm quantity availability for every repeated item.

## Model distinctions worth checking

- Compare Zoom PodTrak P4 with P4next by exact model name. The original P4 supports separate microphone tracks on its card but its USB interface is stereo 2-in/2-out; the P4next supports multitrack USB and 48 kHz/24-bit recording. Check the current manufacturer manual before using these distinctions in a recommendation.
- Reject retailer claims that P4next is a 32-bit-float recorder or has a colour touchscreen when the manufacturer specifies 24-bit recording and an OLED display — adjacent product marketing can contaminate headings.
- Treat Zoom ZDM-1 Podcast Mic Pack as one participant kit, not a four-person setup. Verify that the current package contains the dynamic mic, closed headphones, table tripod, windscreen and XLR cable. Short tabletop tripods may leave the mic too low for comfortable close speech; disclose this rather than assuming any included stand is ergonomically suitable.
- For four local participants plus a remote guest, check channel routing in the manual. A telephone/TRRS or Bluetooth input can replace the fourth mic channel instead of adding another independent input.

## Source selection

Search Estonian-language audio retailers such as Soundium and Pillipood, and compare European specialist shops such as Thomann. Verify product pages, Estonia delivery and destination VAT instead of treating German search-result prices as delivered Estonian prices. Use manufacturer manuals for signal routing and supported recording formats; retailer prose is not authoritative for those details.

Do not persist quoted prices as defaults: sales, stock and bundle contents must be checked for every new comparison.
