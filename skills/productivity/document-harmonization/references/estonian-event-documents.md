# Estonian youth-event documents: rules ("kodukord") + parent consent form

Shape and conventions for recurring events run by the user (BYOC Counter-Strike LAN for young people in Värska, plus a parent consent form). Year-specific values change — the skeleton, wording conventions and pairing rules do not.

## Section skeleton of the kodukord (keep this order)

1. **Üldinfo** — aeg, koht, formaat. Must be formatted exactly like every other section (bullet list).
2. **Registreerimine ja meeskonnad** — registration is mandatory; each team member registers individually; team size; minimum number of registered teams for the event to happen; capacity; tie-break rule (e.g. the teams whose members all registered first); home-county composition requirement.
3. **Mida korraldaja tagab ja mida tuleb ise kaasa võtta** — rooms, tables, chairs, cables, extension leads, sockets/cables per participant; catering not organised → bring your own food and drink; everyone is responsible for their own belongings.
4. **Käitumisreeglid** — smoking incl. e-cigarettes, alcohol and intoxicants banned; being intoxicated on the premises banned; no rude behaviour toward participants or organisers; no damaging or stealing property (damage must be compensated); keep rooms clean, rubbish in bins; no movement in/out after 23:00 (one door open for fresh air); help and set an example.
5. **Mängureeglid** — Steam accounts in good standing; active Valve map pool with "seisuga <date>"; banned: scripts (except buy binds and jumpthrow bind), modified game files, any other unfair advantage; organiser may remove teams to preserve fair play; rule-breaking teams are disqualified.
6. **Reeglite rikkumise korral** — numbered: 1) verbal warning; 2) organiser may send a repeat offender home, police notified for unlawful acts, parents notified for under-18s, the offender's team is disqualified.
7. **Alaealised osalejad (alla 18 aasta)** — consent form required (link); submitable on paper on site or as a digitally signed file by email; the signer confirms having read the rules together with the child; no consent form = no entry.
8. **Info ja kontakt** — named contact person, email, phone; Discord invite used for announcements; where changes are published.
9. **Kodukorra muutmine** — the organiser may refine the rules until the event starts; on-site organiser instructions also apply.

## Conventions

- **Contact:** one canonical address. The organisation address (`…@setomaakoolid.ee`) plus phone is the reliable one; a personal gmail address tends to appear only on the public web page. Pick one, use it everywhere, and tell the user which you picked.
- **Venue:** "Värska Kultuurimaja (Setomaa Kultuurikeskus), Pikk 12, Värska alevik, Setomaa vald, Võru maakond". Registry variants (kultuurikeskus / kultuurimaja / Setomaa Kultuurikeskus) name the same building at Pikk 12 — pick one pair of names and keep it stable.
- **Timing wording:** doors/tech setup from 12:00, tournament start 15:00, end "eeldatavalt keskööni (00–01)". Say the same thing in the rules doc, the web page and the consent form.
- **Registration link** stays an explicit placeholder ("lisa siia registreerimislingi aadress") for the organiser to fill.
- **Rules ↔ consent form pair up both ways:** the rules doc states the consent requirement and links the form; the form states that it was read together with the child and cites the rules. Add the linkage when either side is missing it.
- **Consent form fields:** child's name, parent's name, date and venue, confirmation of having read the rules, catering note, end time, health notes, medication/aids, photo & film consent, parent phone, signature, date. Remove duplicated field lines when reusing an old form.
- Documents are written in Estonian, formal but plain ("tuleb", "on keelatud"); keep the original phrasing where it was already correct instead of paraphrasing for style.
