# Source verification lessons

- Never state a claim from a search snippet. A snippet said Setomaa population decline was 'slower' than elsewhere; the full document showed it holds only in one forecast scenario. Open the document and read the context before writing.
- Download PDFs to the project folder and keep page markers in the extracted text, so every figure can be cited with a page number and re-checked.
- Metric labels in tables can be ambiguous (e.g. 'noorteaktiivide arv' may be groups, not people). Do not turn them into claims about people.
- Mark own inferences explicitly as the author's conclusion, not the source's.
- Reports with no named author on the cover: look up the project web page for the author list before using a corporate author.
- Check the assignment text/rubric (screenshots) before claiming a requirement exists (e.g. first-person form was not required).
- Check length (A4 limit) with a word count; ~500+ words plus references usually overflows one A4.
- Run a final fact-check pass against the source files and fix the draft before delivery.
