# Verified child-drawable Seto vocabulary

Words checked against Seto Instituut "Väike eesti-seto koolisõnastik" (2020) and, where the school dictionary has no entry, EKI "Seto sõnastik" (marked EKI). Spelling follows the koolisõnastik; ' marks palatalization, q is not used.

For school drawing/activity materials (grades 1–9, not ages): compose lists from clearly-Estonian-different, concrete, drawable pairs; the user prefers detail-rich subjects (proper drawing takes >5 min) and rejects trivial ones (single berries, two cherries). Legend: (=) same word in Estonian — excluded when a differently-sounding word is wanted; (≈) near-same/one-letter variant — weak teaching value; (EKI) school dictionary has no entry, confirmed via EKI. Re-check any word in ~/seto_sonad/teemad.txt or tahestik.txt before shipping.

## Tähelepanu – collisions and source conflicts
- kuus = kuus (number); kuus' = kuusk (tree)
- tuul = tuul; tuul' = tool (chair)
- kikas = kukk (rooster); kukk = käbi (pine cone, EKI headword "kukk 2")
- uss = uks (door); huss = rästik (snake)
- kerk: EKI "pühakoda, kirik" vs koolisõnastik "(väike) pink" — conflict, skip
- truba: EKI "karjapasun" vs koolisõnastik "korsten" — conflict, skip
- EKI extended-search fallback (marker: "?! Küsitud kujul ... kasutan laiendatud otsingut") means the exact form is not a headword — check the marker before claiming a match.
